# 比例尺實驗室

給國小六年級學生的「比例尺」互動練習網站。學生用螢幕上的尺量地圖，一步一步算出這張地圖的比例尺，最後畫出圖示比例尺。

**線上版網址：** https://mocuacqu.github.io/Scale-Quiz/

## 這是什麼

一個不需要安裝、不需要登入的單頁網站，電腦、平板、手機都能使用。

網站會顯示一張虛構小鎮的地圖，並隨機出題：告訴學生兩個地點之間的**實際距離**，請學生用畫面上的尺量出**圖上距離**，再算出這張地圖的**比例尺**。

## 目的

本網站對應國小數學六年級上學期「放大圖、縮圖和比例尺」單元中的「比例尺」，作為線上課程最後的實作與檢核活動。希望學生能夠：

1. 理解比例尺是「圖上距離」和「實際距離」的比。
2. 知道比例尺有三種表示方式：比（1 : 20000）、分數（1/20000）、圖示比例尺。
3. 熟悉「先把單位換成一樣，再化成 1 : □」的求比例尺步驟。

## 動機

比例尺的課本習題大多是「給數字、算答案」，學生很少有機會真的拿尺去量一張地圖。到了線上課程，這件事更困難：每個學生的螢幕大小不同，拿實體的尺去量螢幕，每個人量到的長度都不一樣。

這個網站把尺和地圖畫在同一個座標系裡，尺會跟著地圖一起放大縮小，所以不論用什麼裝置，量到的結果都相同。學生可以在全線上的環境裡，完整經歷「量測 → 換算 → 寫出比例尺 → 畫出圖示比例尺」的過程。

## 如何使用

### 學生

1. 打開網站，閱讀題目，例如「從學校到車站的實際距離是 1200 公尺」。地圖上的兩個地點會標成紅色。
2. **量一量**：拖曳尺身，把尺的 0 對準其中一個地點（靠近時會自動對齊）；再拖曳藍色圓鈕旋轉，讓尺的邊緣通過另一個地點，讀出圖上距離。
3. **換單位**：把實際距離換成公分。
4. **寫比例尺**：把「圖上距離 : 實際距離」化成 1 : □。
5. **畫比例尺**：填入圖示比例尺上每個刻度代表的實際距離。
6. 完成後把成果畫面截圖，貼到老師指定的地方（例如 Padlet）。按「換一張地圖，再挑戰一題」可以繼續練習。

卡住時可以按「提示」；同一步答錯兩次，提示會自動出現。

### 老師

- 上課時先分享螢幕示範一題，再把網址給學生各自操作。
- 每一題的地點和比例尺都是隨機的，學生之間不容易直接抄答案。
- 成果畫面有一句「我的比例尺是 1 : □，意思是圖上 1 公分代表實際 □ 公尺」，可以作為學生理解程度的檢核依據。
- 網站不會收集或儲存任何學生資料，重新整理頁面就會從頭開始。

## 題目設計

| 項目 | 內容 |
|---|---|
| 地點 | 學校、公園、圖書館、車站、醫院、超市、郵局、動物園 |
| 圖上距離 | 只出剛好是整數公分的組合（3～12 公分） |
| 比例尺 | 1 : 5000、1 : 10000、1 : 20000、1 : 25000、1 : 50000 隨機出現 |
| 第一題 | 固定是 1 : 10000 或 1 : 20000，難度較低 |
| 進階題 | 抽到 1 : 50000 時，實際距離會以公里呈現，需要多換一次單位 |

## 技術說明

- 純 HTML、CSS 與原生 JavaScript，沒有使用任何外部套件，也不需要後端。
- 地圖和尺都是 SVG，地圖座標 50 單位等於圖上 1 公分。
- 尺的拖曳與旋轉使用 Pointer Events，滑鼠和觸控共用同一套程式。
- 想修改地點或比例尺，可以編輯 `index.html` 裡的 `PLACES` 和 `SCALES` 兩個設定。
